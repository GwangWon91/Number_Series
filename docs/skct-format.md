## 추정 (확인 필요)
| 항목 | 현재 가정 | 반영 위치 |
|---|---|---|
| 문항 형식 | 빈칸 1개 60%, **A·B 두 빈칸 후 A+B·A−B·A×B·A/B 25%**, **n번째 항 묻기 15%** (2026H2-2, 20문항) | 엔진은 빈칸 1개만 — 확장 후보 |

| 항 개수 | 4~10개, 평균 7.9 (2026H2-2) | `types/*.yaml length` |
| 빈칸 위치 | 끝 50% · 중간 50% (2026H2-2) — 분수는 중간이 많음 | `types/*.yaml blank` |
| 숫자 크기 | 작은 수 위주(최대값 중앙 15), 음수 0%, **분수 45%·소수/대분수 30%** (2026H2-2) | `types/*.yaml numbers`, `difficulty` — 소수·대분수는 엔진 미지원 |
| 정답률 | 14~42% (2026H2-2 정오표). 후반 문항이 낮음 — 난이도인지 시간 압박인지 구분 못 함 | 은행 `difficulty` |
| 유형 카탈로그·비중 | 계차·연산 적용·홀짝 교대 비중 큼, 등차·등비 단독은 적음 | `types/*.yaml weight` |
| 오답 선택지 | 정답 근처 값, 흔한 실수 값 | `exam.distractors` |
