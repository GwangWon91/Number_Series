## 추정 (비공개 기출 분석 근거, 확인 필요)
| 항목 | 현재 가정 | 반영 위치 |
|---|---|---|
| 문항 형식 | 빈칸 1개 60%, **A·B 두 빈칸 후 A+B·A−B·A×B·A/B 25%**, **n번째 항 묻기 15%** | `exam.questions` (kinds·pairOps·nthAhead) |
| 선택지 | 5지선다, 대부분 **정렬 안 됨** | `exam.choices`, `exam.choiceOrder: random` |
| 항 개수 | 대체로 5~10개 | `types/*.yaml length` |
| 빈칸 위치 | 끝과 중간이 비슷, 분수는 중간이 많음 | `types/*.yaml blank` |
| 숫자 크기·표기 | 작은 수 위주, 음수 드묾. 정수·분수·소수/대분수가 고루 나온다. 분자·분모 분리 규칙은 약분 안 한 표기(4/8), 값 자체 규칙은 약분·소수·대분수 표기 | `types/fraction.yaml`, `types/rational.yaml` (`display.notation`, `mixNotation`) |
| 선택지 순서 | 정렬 안 됨이 다수, 일부 오름차순 | `exam.choiceOrder: random` — 일부 오름차순은 미반영 |
| 정답률 | 전반적으로 낮고 후반 문항이 더 낮음 — 난이도인지 시간 압박인지 구분 못 함 | 은행 `difficulty` |
| 유형 카탈로그·비중 | 계차·연산 적용·홀짝 교대 비중 큼, 등차·등비 단독은 적음 | `types/*.yaml weight` |
| 오답 선택지 | 정답 근처 값, 흔한 실수 값 | `exam.distractors` |

## 모름 (자료로 확인할 것)
- 유형별 실제 출제 비중과 최근 회차 경향
- 응답 방식(클릭/직접 입력), 오답 구성 방식
- 커뮤니티 복원이 실제 시험과 얼마나 같은지 (숫자·순서 재구성 정도)

- 오답 감점 여부, 20문항 내 난이도 배치
